Hecho pieza por pieza

Cada juego se programa a mano: la física, los controles y hasta esta consola, que está hecha con código y no con un modelo descargado.

  • Pantalla Se juega en el navegador, sin descargas.
  • Cruceta Controles táctiles pensados para iPhone y iPad.
  • Chip Motores y física programados a mano.

Todo empieza como texto

Antes de tener luz y color, un juego es puro código. Esta página también: estas líneas mueven la cámara que estás viendo.

reveal   la consola aparece y sale el sol
macro    la pantalla llena la vista
type     las letras toman el escenario
game     la pantalla cambia de canal
iso      vista isométrica y desarme
code     todo se vuelve texto
color    la consola es tuya
end      vuelve al primer plano
